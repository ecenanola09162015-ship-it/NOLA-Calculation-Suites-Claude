# Roadmap

## 0.1 — Repository foundation

- Monorepo, CI, application shells, shared packages, documentation
- Login-first routes and managed-authentication boundary
- Calculation registry with safety status

## 0.2 — Authenticated shells

- Select and configure the managed identity provider
- Email registration, verification, login, reset, logout, and session tests
- Account-scoped project API and synchronized project list

## 0.3 — Four pilot modules

- RC Column
- Steel Column
- Seismic Loads
- Soil Bearing Capacity

Each pilot is released only after its independent engineering verification set passes on web, desktop, and mobile.

## 0.4 — Private beta

- Web preview on Vercel
- Signed Windows installer
- iOS TestFlight and Google Play internal testing
- Reporting, project export/import, backups, audit logging, and security review

## Phase 2

- RC Beam, Stair, Shallow Foundation, Pile Bearing Capacity, Steel Beam, Base Plate, Wind Loads, Load Combinations
- Slope Stability Analysis

## Later

- Remaining catalogue modules
- Eurocode and Australian Standards
- Licensing, organization administration, and optional enterprise sign-in
